## Quadlet Files

The `quadlets/` subdirectory contains deployable Quadlet `.container`, `.volume`, `.network`, `.pod`, and `.kube` files organized by deployment stack:

| Stack | Files | Contents |
|-------|-------|----------|
| `quadlets/appstore/` | 83 files | Application stack services — container definitions for agent services |
| `quadlets/tank-os/` | 6 files | Upstream bootc image artifacts for Tank OS |
| `quadlets/tank-agent-os/` | 5 files | Bootc image artifacts for Tank Agent OS |

See `assets/deployment/quadlets/INDEX.md` for the full Quadlet file catalog.
