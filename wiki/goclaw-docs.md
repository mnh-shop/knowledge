## What is it?

The official documentation site for the [[goclaw]] Enterprise AI Agent Platform (Go multi-agent AI gateway). It is a **trilingual static single-page app** — English, Vietnamese (Tiếng Việt), and Chinese (中文) — delivered as ~424 markdown pages served through a hash-routed SPA shell on Cloudflare Pages.

The site is unusual among docs repos: it has **no build step** (pure static HTML/CSS/JS with CDN libraries), yet it ships **LLM-facing artifacts** (`llms.txt`, `llms-full.txt` in all three languages) generated by Node/shell scripts, plus an **auto-generated REST API endpoint catalog** that greps the GoClaw source tree. Content is kept in lockstep with the `goclaw/` codebase via a documented triple-sync rule and recurring sync commits.

### i18n mirror scheme

- Full **Vietnamese (`vi/`)** and **Chinese (`zh/`)** mirrors: 130 `.md` files each, section-for-section with EN.
- Navigation titles are trilingual inside the SPA — `js/docs-app.js` `DOC_MAP` stores per-key titles as `docEntry(section, file, 'EN title', 'VI title', 'ZH title')`.
- Language is persisted in `localStorage` (`goclaw-docs-lang`) and switched by "English version / Phiên bản tiếng Việt / 中文版" link markers.
- Mirror is ~99% complete: EN ships 9 `reference/templates/*.md`; VI/ZH ship 8 (no `capabilities.md`).

### SPA shell

- `index.html` — SPA entry with 129 sidebar `<a class="sidebar-link">` entries; loads Tailwind CSS, marked.js, and highlight.js from CDN.
- `js/docs-app.js` (857 lines) — hash-key `DOC_MAP` routing (`#/<key>`), per-language file fetch with EN fallback, markdown rendering + Mermaid, i18n, cached content (`${lang}:${docKey}`).
- `css/styles.css` (900 lines) — dark theme.
- `404.html`, `robots.txt`, and `_redirects` (`/* /index.html 200`) — Cloudflare Pages SPA fallback so all routes serve `index.html`.

### Generation pipeline

- **`build-llms.js`** — concatenates all section `.md` files (reading order) into `llms-full.txt` for EN + VI + ZH (3 language configs, `build-llms.js:29-33`). Run via `npm run build:llms`.
- **`scripts/generate-llms-txt.sh`** — parses the README DOC MAP to emit llmstxt.org-spec `llms.txt` + `llms-full.txt` for all three languages (6 outputs).
- **`scripts/build-api-catalog.js`** — greps `goclaw/internal/http/*.go` + `internal/gateway/server.go` for `mux.Handle/HandleFunc` patterns and generates `reference/api-endpoints-catalog.md` in all three languages. **362 endpoints** (grew from 260 at first generation), pinned to a GoClaw source commit SHA (`fabe86b3`, 2026-06-29). Env: `GOCLAW_SOURCE_PATH`.
- **`scripts/audit-docs.sh`** — scans every page's `goclaw-source: <sha>` frontmatter vs. latest `../goclaw` commit; reports/fixes stale pages (`--update`).

### LLM-facing outputs

Root + mirrors each carry `llms.txt` (index) and `llms-full.txt` (full concatenation, ~34K lines each) — 6 files total, regenerated on every docs sync.

### Governance & docs-sync workflow

- **`CLAUDE.md`** — enforces: (1) source-of-truth = read actual `goclaw/` code (sibling `../goclaw/`), never assume; (2) `archive/` ban; (3) **TRIPLE-SYNC rule** — every `.md` page must appear in `README.md` DOC MAP, `js/docs-app.js` `DOC_MAP`, and `index.html` sidebar together; (4) plan-driven restructure (`../plans/260307-0238-goclaw-docs-restructure/`).
- **`CONTRIBUTING.md`** — page template (Overview → Main Content → Examples → Common Issues → What's Next), tone rules, bilingual process.
- **Sync cadence** — git history shows recurring `docs: sync with goclaw … — EN+VI+ZH` commits (21 of 75 total), each spanning source commit ranges (e.g. `v3.11.3 (29457bb3..364d2d34)`), so docs track the GoClaw source repo release-by-release.

## Deployment

```bash
# Local dev (Cloudflare Pages emulation)
npx wrangler pages dev ./

# Deploy to Cloudflare Pages
npx wrangler pages deploy ./
```

Configured via `wrangler.toml`:

```toml
name = "goclaw-docs"
compatibility_date = "2026-02-26"
pages_build_output_dir = "./"
```

No build command — the site is pure static HTML/CSS/JS (`pages_build_output_dir = "./"` deploys the repo root as-is). The `_redirects` rule `/* /index.html 200` makes the SPA fully routable. `package.json` exposes `dev`/`deploy` (both `npx wrangler pages … ./`), `build:llms`, and `build:api-catalog`.

## Usage

- **As a knowledge base** — read the wiki-first sources: `llms.txt` (index) or `llms-full.txt` (full content, ~34K lines) give an LLM complete GoClaw documentation in one file.
- **As a reference for deployment stacks** — `deployment/` + `reference/` (CLI commands, REST API, WebSocket protocol, config/env vars, DB schema) are the authoritative companion to the [[goclaw]] codebase.
- **As a template for docs sites** — the trilingual SPA + llms.txt pipeline + auto-generated API catalog + triple-sync governance is a reusable pattern for any Go/gateway project's docs.
