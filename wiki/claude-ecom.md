## Overview

Claude Ecom provides e-commerce automation skills and tools designed for use with Claude Code. It enables AI-driven management of online store operations — product listing, inventory updates, order processing, customer support, and analytics — through structured skill definitions that Claude Code can execute.

## Key Features

- **Product Management** — Skills for creating, updating, and managing product listings across e-commerce platforms
- **Order Processing** — Automated order fulfillment workflows and status tracking
- **Inventory Control** — Stock level monitoring and automated reordering
- **Customer Support** — Response templates and customer inquiry handling
- **Analytics & Reporting** — Sales data aggregation and performance reporting
- **Platform Integrations** — Connectors for Shopify, WooCommerce, and similar platforms

## Architecture

The project defines Claude Code skills as structured prompt templates and tool configurations. Each skill wraps specific e-commerce operations with appropriate context instructions, authentication patterns, and expected output formats.
